# Shared Code

This branch includes folders:
- Lightcurves
- BT_Scatter
- Spectral_In

## Lightcurves includes code and data files for creating the 3 tiered plots
## BT_Scatter includes a final version of Brightness Temperature Code, Scatter Plot codes, VLA VLBA comparison plots, extinction corrected V peak plots, Stats code, Gamma ray code.  
## Spectral_In includes spectral index codes and data files needed to make the large spectral index plots.
